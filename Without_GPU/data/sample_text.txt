Arvind Systems Pvt. Ltd. is a fictional Bengaluru-based B2B SaaS company used in this controlled unlearning experiment.
Project Setu is Arvind Systems Pvt. Ltd.'s internal recommendation and ranking platform.
The Setu Recommendation Service coordinates recommendation requests for merchant dashboards and partner integrations.
The Setu Candidate Retrieval Service collects eligible products, offers, and content items before ranking.
The Setu Ranking Model scores candidates using activity, merchant category, freshness, and business-priority features.
The Setu Feature Store stores daily aggregates used by the ranking model.
The Setu Feedback Pipeline records impressions, clicks, skips, and conversions.
The Setu Serving API returns ranked recommendations to dashboard and integration clients.
The Setu Admin Console lets authorized product teams inspect recommendation experiments.

Project Kavach handles risk signals, login anomaly detection, policy checks, and fraud review workflows.
Project Drishti supports dashboards, metric definitions, scheduled reports, and operational analytics.
Project Disha standardizes partner APIs, service contracts, deployment patterns, and reliability work.
